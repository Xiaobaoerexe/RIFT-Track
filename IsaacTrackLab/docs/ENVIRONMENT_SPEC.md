# 城市户外人形目标跟踪环境规格

## 1. 任务边界

单台 Unitree As2 在城市户外场景中跟随指定人物。每回合开始提供一张或一小段目标模板，之后策略持续接收机器人相机 RGB 流以及本体状态；语言不是输入。目标人物沿可行走区域运动，干扰人物和遮挡事件按场景等级生成。

策略初版输出机体速度 `(vx, vy, yaw_rate)`，由低层四足运动控制器负责关节动作和稳定性。这样测试的是视觉识别、重识别、主动搜索、避障和跟随决策；原始力矩控制作为后续独立里程碑。

## 2. 场景组成

- 城市：至少两条街区路线，包含道路、人行道、路口、墙角、窄通道和开放区。
- 可通行性：人物使用导航网格/路点图；机器人使用独立可通行区域，并保留路缘、坡道和不平整区域。
- 障碍：固定障碍必须具备碰撞体；移动障碍具有可复现轨迹与随机扰动。
- 人物：目标、相似外观干扰者、普通干扰者、动态遮挡者分角色管理。
- 遮挡：固定物遮挡、人物横穿、车辆遮挡、转角消失；必须包含可恢复和不可恢复两类事件。

## 3. 传感器与数据隔离

部署 actor 可见：RGB、模板、本体关节状态、基座角速度、重力投影、足端接触；D455 深度作为可开关消融项。目标世界坐标、实例 ID、语义分割、可见率和全局地图仅用于奖励、critic、自动标注和评测，严禁泄漏给部署 actor。

As2 官方 URDF 本身不提供完整 D455/IMU 仿真配置，因此导入 USD 后需：

1. 校准质量、惯量、关节限位和执行器参数；
2. 将 D455 RGB/深度传感器挂到实机一致的安装位；
3. 给基座添加 IMU，给足端和机体添加接触检测；
4. 用实机标定替换占位的内外参和噪声模型。

## 4. 终止和成功

失败并立即终止：目标距离持续超阈值、目标连续不可见超过宽限时间、机体发生强碰撞、跌倒、或越过可行走边界。当前唯一基线为305.176 m路线：在1.25 m/s目标速度下跑满244.2 s且未失败即成功。短遮挡在宽限期内允许，因而“找回”可被单独测量；超过宽限期则属于丢失失败。

碰撞冲量、跌倒高度/姿态和最小目标框面积目前为初值。需先运行静止、正常步行、上下坡、轻擦碰和跌倒基线，再依据分布确定阈值，不能直接把初值作为最终论文设置。

## 5. 六种难度

5分钟和1小时两种时长各含：无干扰、人物干扰、人物干扰+遮挡丢失。1小时是连续3600 s回合，每300 s只写检查点，不重置机器人、跟踪记忆或目标状态。评测使用冻结种子与固定资产划分，训练永不使用评测种子。除成功率外，必须报告跟踪覆盖率、找回率、找回时间、目标距离误差、碰撞/跌倒/越界以及控制平滑度。

## 6. 随机化

训练随机化包括目标/干扰者外观、服装色彩、人体尺度、行走速度、路径、光照、天气外观、相机曝光/模糊/噪声、纹理、障碍布局和 D455 深度缺失。评测随机化受固定种子控制，并保留至少一组从未用于训练的城市布局和人物外观，用于跨资产泛化测试。

## 7. 运行规模

1小时回合在200 Hz下有72万个物理步、30 FPS下有10.8万帧RGB。高质量 RTX 渲染适合单环境评测；训练阶段应使用较低分辨率、降低相机频率、简化碰撞/材质和并行环境，并把高保真长回合作为周期性验证，而不是每次训练都完整运行。
