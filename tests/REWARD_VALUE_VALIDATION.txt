AS2 depth reward/value validation

CPU validation: test_reward_events.py (14 tests) and test_episode_clock.py (4 tests).
The local workspace parity test compares all 15 continuous AS2 reward terms and
their state/action derivatives against baseline 2061be6 with AS2 height .30 m.
It is skipped on deployed machines without the pinned local source directory;
that skip is not a new parity measurement.

Simple variant retains the source reward/termination surrogate and one Vc.
Events/moe use the same-size shared MLP with five selected Vc/Ue output pairs.
Afterstate Ue includes the pre-settlement event context. Its one-step real target
contains the immediate hard event once plus discounted current-policy bootstrap.
Actor adds Ue only at the imagination root. No soft-success label is manufactured.

Recovery reward mode switches are exact real-event algebraic corrections. The
continuous formula is completion independent; actual real totals are unchanged.
However termination remains a hybrid-mode approximation: a Replay start already
marked completed uses the source fall surrogate, whereas pending recovery ignores
falling until the recovery deadline. Imagined future completion is not predicted,
so a completion inside the 32-step window does not switch that continuation rule.
Root Ue fixes the event gradient route, not every hybrid-mode dynamics transition.

Required runtime acceptance still includes real hard success and failure returns,
pre/post-success Ue calibration, post-success Vc and survival, and continuing
command following after the one-time event. Teacher/student require separate
checks. If that controlled test fails materially, event variants must not be
declared validated merely because unit tests or TD losses pass.

The budget calibration is measured against a mature AS2 blind checkpoint in real
PhysX. The 0.9 cap, 8-second event horizons, 0.1-reference failure penalty and
0.002-reference per-second unfinished cost are explicit adaptation choices;
they are not claims about the upstream AS2 reward design. The 3/s positive bound
applies to actual accounting; cancellation terms in the split are not new rewards.
